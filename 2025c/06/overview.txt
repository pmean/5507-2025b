In this module, you will learn how to split and rejoin files. You will 
convert longitudinal files from the long format to the wide format
and vice versa.

Tasks:

Write a SAS program that reads in balance-measures-tall, displays the
first ten rows and shows the general description of the file using
proc contents.

Write a similar SAS program for balance-measures-wide

Show how to create a subset of balance-measures-tall with only the
first of the two replicate measurements.

Show how to create a subset of balance-measures-wide with only the
first of the two replicate measurements.

Discuss how some statistics and/or graphs are easier to compute with
the tall format and other statistics and/or graphs with the wide
format.

Write a SAS program that reads in cholesterol-after-heart-attack and
displays the first ten rows.

Calculate descriptive statistics on group, day, and cholest.

Draw a scatterplot of day on the x-axis and cholest on the y-axis.

Create three smaller files from this data: one for day equals 2,
one for day equals 4, and one for day eqauls 14. Ignore the data for 
day is NA.

Merge the three files you created into one file with data in the wide
format. Calculate the correlation between cholest_2, cholest_4, and
cholest_14.

Take a peek at fasting-turtles.txt, full-moon-er-visits.txt, 
hiv-intervention.txt. One or more of these data sets, either in their
current format or slightly revised, could be used as teaching examples
or programming assignments.
